# Plus: сроки обращения и послеоперационные инструкции

Подготовлен 19.10.2026. Модель и режим: gpt-6-luna, reasoning_effort=medium. Изменение действует только для Plus и его публичного пробного разбора; прежние системные инструкции Free, Pro и VIP сохранены побайтно.

Уточнены: конкретные сроки контакта и оценки состояния, немедленный выезд и запасной маршрут при недоступном хирурге, запрет задерживать помощь ради фото, различие между ограничением введения через рот и отменой терапии, согласование ближайшей дозы, запреты при открытой ране/повязке, сохранение фактов и хронологии, регулярный дневник наблюдений.

Добавлена обработка Markdown-выделения только в строке срочности Plus. Исходные слова и эмодзи сохраняются, уровень не выводится по догадке. Это устраняет случай, когда правильный красный ответ не распознавался из-за жирного заголовка. Остальные тарифы используют прежнюю нормализацию.

## Проверка релизного кандидата

Те же 40 синтетических обращений и 8 повторов; 48 свежих ответов окончательной инструкции сравнены с 48 сохранёнными ответами прежней инструкции той же модели. Все 21 экстренный сценарий сохранили срочный маршрут. 56 слепых AI-сравнений завершились; 43/43 целевых проверки выполнены, критических AI-флагов новой версии нет.

Средняя AI-оценка: 21.975 → 23.150/24. По сумме баллов: 23 выше, 12 равны, 5 ниже. Все различия в пользу прежней версии разобраны в отчёте; AI-баллы и исходные ответы не переписаны. Это настройка на известном синтетическом наборе, без независимой врачебной валидации.

Три версии инструкции по 48 ответов; первые две не выкладывались. Для окончательной версии исходные ответы сохранены, только оформление строки срочности повторно обработано точной функцией релиза без новых запросов к модели. Системный промпт при этом не менялся.

`make check` прошёл на отдельной копии релиза, без незакоммиченных изменений frontend из рабочего каталога. Включены 10 проверок запроса/маршрутизации/нормализации, остальные API, billing, retention, monitoring, frontend/mobile/offline проверки.
