## Что не подтверждено этими тестами

1. Настоящий iPhone: установка на экран «Домой», обновление прежней PWA, клавиатура, безопасные отступы и web push. На Mac нет Xcode/simctl; большой пакет не устанавливался. Safari Responsive Design Mode является предварительной проверкой, а не iOS Simulator. [Apple: Responsive Design Mode](https://developer.apple.com/documentation/safari-developer-tools/responsive-design-mode).
2. Боевые ЮKassa, чеки, сохранённая карта и серверные webhook; вход через реальные Telegram/MAX. Они требуют отдельной проверки после выкладки с соответствующими аккаунтами. Локальные фикстуры не доказывают работу провайдера.
3. Облачный Android push не подключён. Локальные даты повторяются без открытого приложения; изменение даты на другом устройстве поступит в APK при следующем открытии. Android может отложить доставку при экономии энергии. Физическая перезагрузка и длительный Doze отдельно не проверены. [Android: alarms](https://developer.android.com/develop/background-work/services/alarms).
4. Проверка остальных версий Android и принятие магазинами. APK/AAB являются кандидатами, а не одобренными магазинами релизами. Отдельная страница ЮKassa сама по себе не гарантирует соответствие правилам цифровых подписок Google Play: нужно выбрать допустимую платёжную схему для стран распространения. [Google Play Payments](https://support.google.com/googleplay/android-developer/answer/9858738?hl=en).

## Файлы и следующие действия

Пакет расположен в `output/mobile/0.1.0/`: signed APK/AAB, QA APK, серверный пакет PWA, исходники Android, SHA256, отчёт и скриншоты. Ключ подписи хранится отдельно на Mac и не включён в пакет. Материал ключа следует сохранить в отдельной резервной копии.

На Tecno установлены две отдельные иконки: `TemichevVet` с рабочим API и `TemichevVet тест` с локальным стендом. Тестовая версия требует работающего Mac и USB-пробрасывания 8096; обычная версия использует интернет.

Телефон оставлен включённым при зарядке, ADB авторизован; срок автоматического отзыва разрешения выключен. Исходные значения сохранены в `.mobile-tools/tecno-test-settings-before.json`. Временный `caffeinate -is` защищает Mac от сна, пока работает локальный стенд. Крышка Mac должна оставаться открытой, USB-кабель — подключённым.

После отдельного утверждения публикации: резервная копия действующего приложения/данных, выкладка только приложения и APK без замены баз/секретов, проверка HTTPS `/android`, `/mobile`, страницы возврата и health, затем проверка установленной PWA на iPhone. Публикация в магазинах — отдельный этап.
