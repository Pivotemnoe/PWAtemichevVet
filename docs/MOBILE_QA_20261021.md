## iPhone

Создан iOS-проект Capacitor 8.5.3 (iOS 15.4+) с отдельной тестовой сборкой
`ru.temichevvet.app.qa` и релизным идентификатором `ru.temichevvet.app`.
Сохраняется самостоятельный интерфейс с пятью вкладками.
Минимальная версия согласована с используемыми WebKit API офлайн-хранилища:
[`structuredClone` появился в Safari 15.4](https://webkit.org/blog/12445/new-webkit-features-in-safari-15-4/).
JavaScript собирается с целью Safari 15.4, а проверка сборки контролирует
минимальную версию в метаданных и проекте Xcode.

Добавлены системные уведомления, выбор фотографии через WebKit, буфер обмена,
экспорт PDF через системное меню, внешняя страница оплаты и возврат по ссылке
`temichevvet://payment-return`. Сервер распознаёт оба нативных клиента.

Планировщик резервирует до 60 уведомлений. Обычные календарные повторы
бессрочные; для будущего старта и сложных дат используется очередь ближайших
событий. Интерфейс сообщает срок её обновления и число не вместившихся дат.
Проверены конец месяца, високосный год, переход времени, старт в будущем,
стабильность идентификаторов и отклонение повреждённых данных до изменения
системного расписания. Это ещё не подтверждение доставки на реальном iPhone.

По просьбе владельца Xcode на его Mac не устанавливается. Облачный процесс
`.github/workflows/ios.yml` компилирует производственный вариант без подписи
и запускает тестовый вариант на симуляторе GitHub.
[Итоговый запуск `39580981264`](https://github.com/Pivotemnoe/PWAtemichevVet/actions/runs/39580981264)
успешно завершился на исходниках `fe7102fc0d9c5cc77403830121348baaaacee305`:
производственная сборка прошла, все семь UI-проверок прошли без ошибок.
Среда: Xcode 26.6 (17F113), симулятор iPhone 17 Pro с iOS 26.4.
Производственные метаданные подтверждают версию 0.1.2, минимум iOS 15.4,
API `https://temichevvet.ru` и отключённый тестовый режим.

Это устранило наблюдавшуюся потерю соединения при входе; последующие полные
прогоны подтвердили вход и сохранение сессии после перезапусков.

`readTimeout`; прежние 15 секунд могли обрывать долгий разбор. Для обычных
запросов сохранено короткое ожидание. Изолированный сервер проверен с
искусственной задержкой 17 секунд, без OpenAI и реальных сообщений;
сценарий через интерфейс iPhone прошёл в указанном облачном прогоне.
