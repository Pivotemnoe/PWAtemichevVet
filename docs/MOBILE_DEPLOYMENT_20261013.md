# Публикация TemichevVet Android/PWA 0.1.1

Опубликовано по прямому разрешению пользователя 13 октября 2026 года, 14:49 МСК. Версия APK 0.1.1, versionCode 2; серверные и PWA-ресурсы `20261013-mobile-14`.

- Страница установки: https://temichevvet.ru/android
- Подписанный APK: https://temichevvet.ru/downloads/TemichevVet-0.1.1.apk
- PWA с собственным меню: https://temichevvet.ru/mobile

На главной странице сайта добавлена заметная ссылка установки Android/iPhone; Android-карточка ведёт к скачиванию APK. Для установленной PWA нужно закрыть и снова открыть приложение. Авторизация остаётся общей с сайтом.

## Выпуск и сохранность данных

Боевой сервер `msk-1-vm-d817`, приложение `/opt/temichevvet/pwa`, база `/opt/temichevvet/data/pwa.db`, служба `temichevvet_pwa.service`. Выкладка прошла через существующий NL → RU SSH-маршрут с проверкой ключей хостов.

Перед заменой файлов сохранены код, исходный `.env` и согласованная SQLite-копия в `/opt/temichevvet/backups/mobile-011-20261013T114933Z`. Каталог закрыт правами 0700; база и конфигурация — 0600. Штатная инициализация добавила колонки фото и ключей запросов, а также уникальные индексы. Исходная база не заменялась. `PRAGMA quick_check=ok`, нарушений внешних ключей 0; прежние пользователи, питомцы, история, платежи, периоды доступа и квоты подписок сохранены.

Из зависимостей в собственную серверную `.venv` добавлен только Pillow 11.3.0. `.env`, владелец и права файла, рабочие настройки каналов и оплаты сохранены. Перезапускалась только PWA-служба. Nginx и таймеры followups/monitor/backup сохранили активное состояние; бот сохранил исходное неактивное состояние.

Серверная конфигурация содержит локальный `APP_BASE_URL`. Для Android-возврата ЮKassa теперь используется доверенный публичный адрес с HTTPS: `https://temichevvet.ru/mobile/payment-return`. Возврат в приложение сам по себе не выдаёт оплаченный доступ: остаётся серверная проверка статуса платежа.

## Проверки

`make check` и календарные release JUnit прошли до выкладки. На изолированной копии приложения и базы с отключёнными платежами, SMTP, MAX, Telegram, OpenAI и push проверены нормализация фото, владение, удаление фото, отсутствие дублей веса/наблюдений/дат, отключение напоминания и признаки возможностей нового API.

После перезапуска локально проверены здоровье сервиса, публичные страницы, приватность API и хеш APK. С Mac по публичному HTTPS прошли 15 проверок: главная, установка, PWA, возврат оплаты, манифест, service worker, новые JS/CSS/изображения, анонимный API 401 и скачивание APK. Подпись проверена `apksigner`, AAB — `jarsigner`.

Опубликованный APK: 12 201 120 байт, SHA256 `a913f3e6ec4035e53bdbe09e6e74c3c2d8b678e5c3c0054dd54fcf1ed304a14f`. SHA256 сертификата подписи: `8828c7f8d5f83154aaa894e1ec657e5e2edd9423da6bdb779e834c63c7435b34`.

Браузерная приёмка: переход по ссылке главной на страницу установки, обе платформы и версия 0.1.1; затем собственный интерфейс `/mobile` при 390 × 844 с пятью нижними вкладками. Ошибок и предупреждений консоли не обнаружено. Скриншоты — `output/playwright/production-download-20261013.png` и `production-pwa-390-20261013.png`.

Первый запуск выкладки автоматически вернул прежний код из-за чувствительности проверочного скрипта к регистру HTTP-заголовков. Проверка исправлена нормализацией имён заголовков. Повторная выкладка прошла полностью; это не сбой приложения. Дополнительные колонки оставались в базе, без восстановления поверх пользовательских записей.

## Границы проверки и восстановление

Реальные платежи и внешние сообщения не отправлялись. Предыдущая аппаратная проверка 0.1.1 на Tecno подтверждает фото и офлайн-очередь на QA-стенде; после публикации телефон отсутствовал в ADB, поэтому повторная установка финального файла не заявляется. Настоящая установка/обновление PWA на iPhone остаётся за владельцем. AAB подготовлен, но в магазины не отправлялся.

Для возврата предыдущего кода использовать закрытую резервную копию, сохранить текущую базу и вернуть только файлы приложения с прежними владельцами/правами, затем перезапустить PWA и проверить здоровье сервиса. Аддитивные колонки совместимы с прежним кодом; копию базы не восстанавливать поверх более свежих пользовательских данных без отдельного решения.

Квитанция выкладки и публичные проверки сохранены локально в `.mobile-tools/deploy-20261013/`; пакет выпуска содержит сокращённую квитанцию `PRODUCTION_DEPLOYMENT.json` и `PUBLIC_VERIFICATION.json` без пользовательских записей и секретов.
